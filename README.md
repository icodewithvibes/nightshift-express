# Nightshift Express

Original browser highway driving game (Three.js, Rapier, TypeScript, Vite). Play: https://icodewithvibes.github.io/nightshift-express/

Multiplayer: Multiplayer → Create room, share the 4-character code; friends type it to join. No sign-in. Peer-to-peer over WebRTC (PeerJS broker for signalling only). If the host leaves, another rider takes over.

Saves: Settings → Your save (copy code, download file, restore).
